# MIDI semantics and Fountain Coach extensions

The declared MIDI Association corpus is the normative authority for MIDI 2.0 semantics. The canonical object may also contain implementation structures required by Fountain Coach’s MIDI backplane, FCIS, telemetry, lifecycle, or evidence system. Those structures are implementation-derived and must remain visibly separate from MIDI requirements.

The inverse coverage ledger identifies MIDI source requirements by document and version. An extension can appear as a representation target only when its relationship to a MIDI requirement is explicitly justified; an FCIS or backplane field never satisfies a MIDI requirement merely because it is nearby in the object.

The public claims therefore distinguish:

- MIDI Association normative semantics;
- Fountain Coach implementation and support structures;
- runtime and evidence behavior; and
- physical hardware interoperability.
